Authors: Gundo Tshavhungwe (26855412) and Anathi Nyangintsimbi (23625695)

ILS Code
How to run:
1. Extract the zip file to a folder.
2. Open a terminal/command prompt in that folder.
3. Run: java -jar IteratedLocalSearchKnapsack.jar
4. Enter a seed value (e.g., 9876) and press Enter.
5. Enter the folder path containing the problem files. Type "data" (without quotes) and press Enter.

The program will process all .kp files in the "data" folder and print a table with:
- Instance name
- ILS best value
- Known optimum (for reference)
- Best solution bitstring
- Runtime in seconds

The program uses the same seed for all runs. Results are reproducible.
